# 扫雷 4×5 · 纯色高分挑战 & 标注推理器

单文件跨平台（Windows / Linux / iOS / Android）网页游戏与一步前瞻 AI 推理推荐器。

## 核心特性

1. **单文件零依赖跨平台运行**：打开 `minesweeper-4x5.html`（或部署 GitHub Pages 访问 `index.html`）即可在电脑与手机浏览器直接运行。
2. **仅显示颜色，不显示具体雷数**：
   - **绿色**：周围 0 颗雷（`+1` 分）
   - **蓝色**：周围 1–2 颗雷（`+5` 分）
   - **红色**：周围 3–4 颗雷（`+20` 分）
3. **超过 30 分不结束，冲刺最高总分**：得分 `> 30` 达成获胜及格线后继续进行，直到 16 个安全格全部被点开（完美清盘）或点到炸弹触发 Canvas 粒子爆炸特效后结算总分。
4. **右键 / 手机触控标注颜色 · 一步前瞻推荐模式**：
   - **电脑端**：在任意格子上点击鼠标右键弹出选色菜单（或切换为右键循环 `绿 → 蓝 → 红 → 清除`）。
   - **手机端**：使用棋盘正上方的快捷画笔栏（`标绿 / 标蓝 / 标红 / 弹窗选 / 清除`）轻点格子，或长按格子 `0.35 秒` 呼出底部抽屉选色菜单。
   - **一步前瞻（1-Step Lookahead）推理**：严格仅依据颜色对应的雷数范围（`0` / `1~2` / `3~4`）过滤全部 4845 种 4 雷布局，计算每格精确含雷率与下一步预计可解锁的 `0%` 必安全格数量，实时标注最佳落点（首点安全时 `>30` 分达标率达 **80.99%**）。

## 目录结构

- `minesweeper-4x5.html` / `index.html`：主页面（含标注颜色推荐模式 + 随机实战游玩模式 + 手机端适配）
- `minesweeper-4x5-backup.html`：纯色高分挑战独立备份版
- `analysis/engine.js`：纯色范围过滤与一步前瞻核心推理引擎
- `analysis/game.template.html`：界面与交互模板
- `analysis/build.js`：单文件 HTML 打包脚本（`node analysis/build.js`）
- `analysis/smoke.js`：无头自动化验证测试（`node analysis/smoke.js`）
- `analysis/diagnose.js` / `analysis/compare_policies.js`：全量 3876 局策略对比与逐回合复盘诊断工具
